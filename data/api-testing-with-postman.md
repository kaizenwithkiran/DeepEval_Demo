## Who this course is for

Testers who only test through the UI and want to move testing down the stack, and
developers who want a structured way to test their own APIs.

## Syllabus

1. **HTTP fundamentals** — methods, status codes, headers, query versus path parameters,
   content negotiation.
2. **Postman essentials** — collections, environments, variables, pre-request and test
   scripts, `pm.expect` assertions.
3. **Authentication** — Basic auth, API keys, bearer tokens, OAuth 2.0 flows, refreshing
   tokens inside a collection.
4. **Data-driven runs** — collection runner, CSV and JSON data files, Newman on the
   command line, Newman in CI.
5. **Mock servers and contract checks** — Postman mock servers, example responses,
   JSON schema validation.
6. **REST Assured** — given/when/then syntax, request and response specifications,
   serialisation with POJOs, JSONPath and XMLPath extraction.
7. **Integrating REST Assured with TestNG** — assertions, data providers, reporting.
8. **GraphQL basics** — queries, mutations, and how testing them differs from REST.
9. **Performance smoke checks** — response-time assertions and what they can and cannot tell you.

## Tooling used

Postman, Newman, Node.js, Java 17, Maven, REST Assured, TestNG, JSON Schema,
GitHub Actions.

## Projects

- **Project 1**: A full Postman collection for a public bookstore API with environments

- **Capstone**: A REST Assured + TestNG suite covering CRUD, auth and negative cases,
