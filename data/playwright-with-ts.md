## Who this course is for

Manual testers moving into automation, and automation engineers who already know
Selenium and want a modern, faster browser-automation stack. No prior Playwright
experience is assumed.

## Syllabus

1. **TypeScript foundations** — types, interfaces, classes, async/await, modules.
2. **Playwright setup** — installing Playwright, project structure, `playwright.config.ts`,
   browsers and channels.
3. **Locators and auto-waiting** — role-based locators, `getByTestId`, chaining, strictness,
   why Playwright does not need explicit waits.
4. **Assertions** — web-first assertions with `expect`, soft assertions, custom matchers.
5. **Test organisation** — fixtures, hooks, tags, test steps, parallel workers and sharding.
6. **Page Object Model** — building maintainable page objects in TypeScript.
7. **API testing with Playwright** — `request` fixture, mixing UI and API in one test.
8. **Network control** — request interception, mocking responses, HAR replay.
9. **Visual and accessibility testing** — screenshot comparison, `@axe-core/playwright`.
10. **Debugging and reporting** — trace viewer, UI mode, HTML reporter, Allure integration.
11. **CI/CD** — running Playwright on GitHub Actions and Jenkins, Docker images, retries.

## Tooling used

Allure Report, Docker.
