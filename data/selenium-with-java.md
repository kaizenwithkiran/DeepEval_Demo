## Who this course is for

Complete beginners to automation, and manual testers in organisations that have
standardised on Java and Selenium. This is the longest and most foundational course
in the catalogue.

## Syllabus

1. **Core Java for testers** — data types, OOP, collections, exceptions, streams, file I/O.
2. **Selenium WebDriver basics** — architecture, drivers, browser options, Selenium Manager.
3. **Locators** — id, name, CSS selectors, XPath axes, relative locators.
4. **Synchronisation** — implicit wait, explicit wait, fluent wait, and when each is correct.
5. **Advanced interactions** — Actions class, JavascriptExecutor, frames, windows, alerts,
   shadow DOM, file upload and download.
6. **TestNG** — annotations, groups, priorities, data providers, parallel execution,
   listeners, `testng.xml` suites.
7. **Design patterns** — Page Object Model, Page Factory, Singleton driver, Factory pattern.
8. **Data-driven testing** — Apache POI with Excel, JSON and properties files.
9. **BDD with Cucumber** — feature files, step definitions, hooks, tags, Cucumber reports.
10. **Build and CI** — Maven lifecycle, Jenkins jobs, Selenium Grid 4, Docker, Allure Report.

## Tooling used

## Selenium or Playwright?

Pick Selenium With Java when your team already runs a Java stack, when you need
broad legacy browser coverage, or when job postings in your region ask for Selenium.
Pick Playwright With TS when you are starting fresh, want faster and less flaky runs
out of the box, and are comfortable in the JavaScript ecosystem. Both courses teach
the same underlying testing discipline; only the tooling differs.
